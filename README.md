# 🐈 Корма для кошек: составы и цены

Пет-проект: интерактивное сравнение 62 кормов для взрослых кошек. В выборке есть:

- сухие и влажные корма;
- корма для стерилизованных и для обычных кошек;
- российские и импортные.

Для каждого корма можно посмотреть:

- что на самом деле в составе;
- сколько корм стоит в разных магазинах;
- насколько честно соотносятся цена и качество.

**▶ Открыть страницу: https://intstage.github.io/cat-food-ru/**

## Что внутри

- **Сводная таблица.** Фильтры по типу, назначению и стране, поиск по бренду и ингредиентам, сортировка. Нажмите на строку, чтобы раскрыть полный разбор: первые ингредиенты, гарантированный анализ, из чего сложился балл и цены по каждому магазину.
- **Лучшие в каждом сегменте.** По три корма для сухих и влажных, для стерилизованных и для обычных кошек.
- **Сравнение выбранных кормов.** Отметьте до 6 кормов галочками и нажмите «Сравнить». Корма встанут рядом: баллы, цены, анализ на этикетке, минералы и состав. Лучшее значение в каждой строке отмечено ★. Выбор сохраняется в адресе страницы, поэтому ссылкой на сравнение можно поделиться. Пример: [Best Dinner, Farmina, Karmy и Royal Canin](https://intstage.github.io/cat-food-ru/?cmp=95846,79132,127215,1018).
- **Диаграмма «качество — цена».** Наверху справа — хороший состав за меньшие деньги.
- **Цены в 7 магазинах.** Petshop, Ozon, Яндекс Маркет, Wildberries, Магизоо, Четыре Лапы и Зоозавр. Цена дана за 100 г, а также пересчитана на 300 г и 1,5 кг.
- **Адаптивная вёрстка.** На ПК — полная таблица, на планшете — таблица с закреплённым столбцом названий, на телефоне — карточки. Есть тёмная тема.

## Как считается рейтинг

Итоговый балл от 0 до 100 складывается так:

| Баллы | Критерий |
|---:|---|
| 30 | Белок на сухое вещество (28% → 0, 55% → 30) |
| 20 | Первый ингредиент: конкретное мясо или рыба, мясо без указания вида или растительное сырьё. Штрафы за изоляты растительного белка, сахар и красители |
| 15 | Углеводы на сухое вещество (45% → 0, 5% → 15) |
| 10 | Прозрачность: раскрыт ли состав, полнорационный ли корм |
| 10 | Жирность под задачу: 10–16% на сухое вещество для стерилизованных, 14–24% для обычных |
| 15 | Цена за 100 г среди кормов того же типа: сухие сравниваются с сухими, влажные с влажными |

«Качество» — те же баллы без цены (85 из 100), пересчитанные в шкалу 100. Подробнее о методике и ограничениях — на самой странице и в [metodika.md](metodika.md).

## Структура

```
index.html                собранная страница (её отдаёт GitHub Pages)
src/template.html         вёрстка и логика страницы (HTML, CSS, JS без зависимостей)
src/build.py              объединяет составы, страны и цены, считает баллы → data/data.json
src/assemble.py           встраивает данные в шаблон → index.html и CSV
data/petshop/details.json карточки кормов с Petshop: состав, фасовки, цены
data/compositions.json    разобранные составы и гарантированный анализ
data/countries.json       страна производства (по характеристикам Ozon)
data/prices/*.json        цены по магазинам с фасовками и ссылками
data/korma-dlya-koshek.csv итоговая таблица для Excel (разделитель «;»)
collectors/               скрипты, которыми собирались данные Petshop, Четырёх Лап и Зоозавра
tests/                    проверки сборки
```

## Как обновить

Нужен Python 3.10 или новее, сторонние библиотеки не требуются.

```bash
make            # пересобрать data.json, index.html и CSV
make serve      # открыть локально на http://localhost:8000
python3 -m pytest tests   # проверки (нужен pytest)
```

Чтобы обновить цены, замените файлы в `data/prices/`, сохранив формат, и запустите `make`. Формат записи:

```json
{"id": 1018, "shop": "ozon", "found": true, "url": "…",
 "offers": [{"weight_g": 400, "price_rub": 512, "in_stock": true}]}
```

## Как собирались данные

- **Petshop.** Открытый API каталога (`/api/v4/site/catalog/products/`): из него взяты список кормов, составы, фасовки и цены для Санкт-Петербурга.
- **Ozon, Яндекс Маркет и Wildberries.** Поиск по каждой позиции в обычном браузере. В таблицу попадали только точные совпадения бренда, линейки, вкуса и типа корма. Цены Ozon указаны с Ozon Картой, Яндекс Маркета — с Яндекс Пэй, Wildberries — с WB Кошельком.
- **Четыре Лапы и Зоозавр.** Публичные страницы поиска и API, которые использует сам сайт. Регион — Москва.
- **Бетховен и ЗооОптТорг.** Цен нет: сайты не открылись из сети, с которой шёл сбор. Обходить защиту сайтов не стали.

Цены — снимок на 4 ноября 2026 года.

## Дисклеймер

Это ориентир по составу и цене, а не ветеринарная рекомендация. Гарантированный анализ на этикетке — это заявленные производителем значения, а не лабораторный замер. При болезнях почек, МКБ или аллергии корм подбирает ветеринар.
